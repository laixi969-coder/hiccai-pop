# 前 2–3 秒内容钩子：先让人愿意看，再让结尾值得看

这是创作与审稿方法，不是平台算法定律或停留率保证。用于每条创意的开场设计；默认反转、直接演示和无人拍法都适用。

## 1. 一个钩子必须交代三件事

**已经发生的异常 + 观众关心的后果/回报 + 此刻没给完的答案。**

- 异常：与日常预期相比，究竟哪里不对？须能指向画面中的具体主体与动作。
- 动机：为什么值得多看两秒？可以是小损失、即将碰撞的关系、熟悉的尴尬、想完成的视觉过程，不必总是危险或愤怒。
- 缺口：观众想知道的是哪一个具体答案？如“他为什么把最后一点也倒回去”，而不是万能的“接下来会怎样”。

单纯陌生不等于有趣；红色物体、一个人皱眉、极近特写，都可能只是构图。字幕提问也不能自动制造悬念。

**钩子与反转分开验收**：遮住后半段，只看前三秒，开头仍应值得停留；看完整条后，结尾必须回答前三秒提出的问题。结尾好不能补偿开头慢，开头强也不能替代产品因果。

## 2. 0–3 秒的三个节拍

| 时段 | 任务 | 需要写出来的东西 |
|---|---|---|
| 0–1 秒 | 把异常直接放在第一帧附近 | 谁/什么处于什么位置，正在做哪个反常动作；不先走进房间、摆道具、介绍自己 |
| 1–2 秒 | 让利害或矛盾变得明确 | 第二个动作/反应/物件关系，让观众知道这是在争抢、要穿帮、即将失败或有值得看的变化 |
| 2–3 秒 | 增加一条证据，保留具体答案 | 动作被打断、出现第二条矛盾线索、结果只兑现一部分；指明观众现在想问哪句话 |

这是节拍而非必须切三个镜头。一个连续镜头可完成三个节拍，片长也不用硬凑到3秒。若1.5秒已经建立问题，就往后推进。

## 3. 八种钩子机制与失败边界

| 机制 | 让人想看的理由 | 开场动作示意 | 容易写坏的方式 |
|---|---|---|---|
| 即将发生的小损失 | 想知道能不能保住 | 最后一点液体正要倒走，另一只手立即托住杯底 | 只说“很珍贵”，画面没有损失 |
| 动作突然受阻 | 想知道为什么不让做 | 人刚坐下，椅子被挪开一小截，阻拦者认真指着地上的界线 | 随机推搡，后文解释与动作无关 |
| 可见矛盾 | 两件已看见的事不能同时成立 | 两个等大的杯子放在尺旁，有人还在一滴一滴调平 | 只靠标题写“不可思议” |
| 过度认真的小事 | 想知道值得如此较真的到底是什么 | 用尺、计时或裁判姿势处理明显很小的日常分歧 | 道具只是装饰，结尾无实际用途 |
| 结果先出现、来源缺失 | 想知道结果由什么造成 | 桌沿不断滴水，但下方水盆已经接在正确位置 | 随便拍一滴水，既无矛盾也无关切 |
| 关系越界/反常待遇 | 想知道谁在占便宜、是否误会 | 自己的座位被封条占了，另一人却给旁边空位铺好垫子 | 全靠“男友出轨”等大词制造情绪 |
| 熟悉尴尬被当场抓住 | 代入“我也干过”，想看如何收场 | 偷伸的手突然停住，正对面已有另一只手等着抓现行 | 先讲两人认识十年的背景 |
| 感官过程即将兑现 | 想看完成、对齐、溢出前被稳住的结果 | 最后一块拼图将落位，旁边一块却自行退出 | 慢镜头和音效很重，过程本身没有变化 |

每条选一个主机制，最多加一个辅助。不要把惊吓、喊叫、夸张音效视为默认强钩子；可用受控道具制造小冲突，不扩大到真实伤害。

## 4. 原样本的钩子应怎样分析

以下判断基于用户的文字样本，不等于看过原视频或证明留存效果。

- **A12 咖啡泼白衣**：动作、对象与损失直接关联，适合“即将损失”。可借“动作发生在第一帧”的结构，不继承真实摔倒或保证不沾污的效果。
- **A11 工位落泪**：仅拍人擦眼泪是弱开场。更明确的开场是纸巾已经攥成团、擦完立刻又抽一张，肩膀同时有不相称的规律动作；顶部文字给“赶工”猜测。是否足够强仍要看表演和画面，不能因为结尾切洋葱好笑就自动通过。
- **B08 室友标签**：依次读标签会消耗前三秒。改成手刚拿走鸡蛋，另一只手立即把对应标签数字划掉或补上；“室友开始计费了”的猜测有即时行为依据。最终若揭晓为备餐计数，必须解释这次计数，不能另塞一张暖心纸条蒙混过关。
- **B07 洗杯器**：强项是按压动作与清洁过程，不必先讲主管催单。若用户允许直接演示，可从第一只脏杯压下开始；不能为了统一零产品规则浪费已有的动作钩子。
- **A39 冰淇淋化掉**：先拍人接电话离开，缺乏停留理由。可先拍勺子落下却捞不到预期的冰淇淋，桌边液体已接近手机道具，建立“发生了什么”的缺口；真实融化过程需要时间，不能剪成即时性能证明。

## 5. 审稿：五个问题逐项通过，不用总分抵消失败

1. **前三秒单独看，发生了什么？** 必须能描述动作与矛盾，不能只说气氛紧张、有人好奇。
2. **观众具体在等哪个答案或结果？** 写出一句自然人会问的问题。若问题只有看完结尾才存在，开头不合格。
3. **为什么现在值得看？** 指出一处可见损失、反常关系、熟悉尴尬或感官回报；不能只回答“有悬念”。
4. **到第三秒有没有新进展？** 不是同一表情放大三次，不是三秒静止字幕。
5. **结尾是否兑现同一个问题？** 把开场承诺和结尾答案并排写。商品只是突然出现、开场对象被遗忘、反转依赖无关新设定，都退回重写。

画面、短字幕、声音可以协作。隐藏产品时，遮住的是答案，不能连矛盾也遮住。声音型开场也需可见反应或同步动作；静音测试允许读一行短文字，不要求一帧解释整个人物关系。

## 6. 输出与评估

每条创意在正文前单列：**0–1 秒 / 1–2 秒 / 2–3 秒 / 观众想问什么**。把三个节拍对应到后面的镜号，可合并重复文字，但不能省略动作。再写中后段，检验承诺兑现。

内部先尝试三个不同机制的开头，淘汰只换台词的版本。用户要五条时，先比较五条的钩子；不许五条都靠“拍局部、最后拉远”充数。制作成本、出镜限制和产品事实仍需通过，不能用强开场换取虚假效果。

这只能完成案头审稿。若后续进行实际A/B拍摄，保持主体、后半段、时长和投放条件尽量一致，替换开头；只有获得实际平台数据后才讨论哪条停留表现更好，不能以自评打分冒称已验证。

## 7. 新版 160 条带来的补充：把钩子落在证据上

- **临界状态**：进度条、剩余量或即将合拢的结构，必须与待解决任务同框，不能只有巨大的倒计时。参考 K12、P09 的结构，删除未证实的损失与危险操作。
- **数据矛盾**：D13 的价格对照先确认同一规格与口径；不同比较对象不能靠剪辑冒充冲突。
- **输入输出缺口**：D02 的粗略输入引出转化期待，结尾应展示同一输入的实际输出，不能换无关成品。
- **微小但具体的麻烦**：P64 的梳子卡毛无需流血也成立；第一帧直接给卡住的状态，后续兑现清理动作。

前三秒写出“证据是什么、在哪、能否读到”。录屏优先一个窗口、一个选区、一行短字幕；可用光标依次引导观察，不能要求同时读长聊天、英文字幕和小字参数。0–1/1–2/2–3秒可以是一个动作的持续进展，不强制三个新动作。

产品、界面或用途什么时候露出另行标注。“观众还不知道这是广告”不等于“产品还没出现”。新增例子和逐条修正见 [当前索引](sample-bank-v3.md)；上文 A/B 案例仍属于历史90条。
