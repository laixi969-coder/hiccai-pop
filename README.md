# hiccai-pop

海外短视频创意与分镜 Skill，适用于 Codex、Claude Code 和 Antigravity。

核心创作标准：**第一秒出现简单、可见的异常；中段埋下公平伏笔；结尾用欧·亨利式反转重新解释前面的画面。** 产品可以成为谜底，也可以在反转后直接进入清楚的硬广。优先考虑手机实拍、小团队和可核实的产品信息。

---

## 核心方法

1. **先想结尾，再倒推开头**：观众以为 A，前面已出现伏笔 Y，结尾揭示 B；B 必须让前面的画面产生新含义。
2. **第一秒能静音看懂**：一个可见异常、一个具体问题，不依赖背景介绍、复杂特效或密集字幕。
3. **低成本、可直接执行是硬要求**：默认一个场地、最多两名出镜人物、三个关键道具和六个镜头。每条创意写清主体位置、动作与可见结果，并提供照着就能做的实拍方法或 AI 生成描述，以及具体省钱办法。
4. **产品承担因果角色**：产品可以是反转谜底，也可以在反转之后用一个明确卖点收尾。未知型号不编造参数或性能。
5. **按需求交付**：要五个创意就给五个不同的故事机制；选中方向后再扩展逐秒分镜。
