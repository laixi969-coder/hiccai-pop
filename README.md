# hiccai-pop

海外爆款短视频创新总监与分镜引擎 —— Claude Code / Antigravity Agent Skill。

基于对 **Roxy浏览器社媒灵感库、境策通出海、Kris的海外笔记、limes的海外社煤笔记、kimono的海外观察笔记、郑和助手达人库** 等专业账号拆解的真实爆款视频基因研发。拒绝简单照搬案例，以**“四大创新算子”**与**“四级神经反射模型”**为底层方法论，为任何出海产品/跨境品牌生成极高完播率与转化率的原创短视频分镜脚本。

## 核心方法论与能力矩阵

1. **认知框架破裂（Frame Breaking Theory）**
   - 90% 极度熟悉的生活载体 ⊕ 10% 绝对不可能发生的异常变量 ➡️ 瞬间打破用户无意识刷屏的“默认模式网络”。
2. **四大底层创新算子（The 4 Innovation Operators）**
   - **媒介异化（Medium Alienation）**：打破第四面墙，把屏幕与现实载体当物理道具（如撕纸透视广告、多手机拼屏流淌）。
   - **语境劫持（Contextual Hijacking）**：借用生死、危机、惊险等生物本能语境起跑（如伪车祸开场、火警逃生）。
   - **双轨撕裂（Dual-Track Dissonance）**：听觉与视觉异质对抗制造认知过载（如抓马复仇 Storytime + 沉浸护肤）。
   - **荒诞极化（Absurdist Hyperbole）**：将单一产品卖点放大 1000 倍推向物理与荒诞极限（如跑车轮毂测支架、大斧劈水桶贴胶带）。
3. **四级神经反射机制（The 4 Reflexes）**
   - 痛觉共鸣反射、破坏奇观反射、极速救赎反射、认知失调反射。
4. **六大微观视听心机（The 6 Cinematography Tricks）**
   - 暴力极限测试、橡皮擦单帧抹除、丑态狼狈灾难、奇观解压猎奇、违背物理感知、第一人称沉浸代入。
5. **导演级秒级分镜执行表**
   - 时间轴精确到秒、景别运镜机位、动作表演指导、英文台词+中译、粗体跳动字花字、精确拟声音效（SFX）、首尾相接无缝死循环（Infinite Loop）。
6. **流量与投放护航**
   - 原生英文标题 × 3（含 Trending 标签）、评论区预埋引战雷（制造高权重评论）、TikTok / Reels / Shorts 平台差异化策略。
