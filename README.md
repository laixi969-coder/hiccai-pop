# hiccai-pop

默认一部手机即可拍摄、录音和基础剪辑的海外短视频创意与分镜 Skill，适用于 Codex、Claude Code 和 Antigravity。

当前版本：**3.3.0**。基于新版 `tiktok.docx` 的 160 条文字方案更新：KOC 30 条、数字工具与 Faceless 50 条、实体商品 80 条。文档自述的播放量、账号与产品效果未核验，不作为已验证爆款背书。

核心创作标准：**先用熟人视角和生活小事建立关注，用可见异常与短顶部文字引导误判，再让产品的真实能力解释前面的画面。**

## 核心方法

1. **先分清故事机制**：误会重释、秘密工具、关系翻转，与情境解围、结果演示分别评价；不把所有产品效果都叫欧·亨利反转。
2. **以3秒内建立观看动机为目标**：先明确观众与回报，再选画面、文字、声音或结果过程主导。分别检查看懂、在意、愿意继续；封面与视频开头分开。写出准确首屏内容，不能靠填满三个节拍自证强钩子，结尾必须兑现承诺。
3. **保留最后一镜揭晓**：最后一镜可以从约 70% 处开始，连续完成揭晓和短反应。用户指定样本式多镜头收尾、提前露出、直接演示或硬广尾板时切换对应模式。
4. **单手机完成**：默认一个现成场景、最多两名总参与者、三件已有道具、3–6镜、1–2个手机摆位；自然光或现有灯，手机内硬切和字幕。不依赖第二手机、摄影团队、专业设备、定格或AI特效；每条明确手机怎么放、谁操作、怎么剪。用户明确要求其他制作规格时才切换。
5. **混合出镜**：五条默认 2–3 条无人，其余有人；仅手部不算无人。局部无人探索不覆盖整组偏好。
6. **有依据才写效果**：未知型号不编参数，文档里的夸张性能不视为事实；循环必须交代实际接点，不机械加“因为——”。

7. **录屏可执行、证据可核对**：初始状态、实际操作、输出、核对贯通；Faceless、仅手部、完全无人分开，模拟界面不冒充实测。
