# hiccai-pop

默认一部手机即可拍摄、录音和基础剪辑的海外短视频创意与分镜 Skill，覆盖实物带货、软件/App/数字资产推广与纯内容涨粉，适用于 Codex、Claude Code 和 Antigravity。

当前版本：**3.5.2**。根据 `viral_video_knowledge_base_and_agent.md` 与 `viral_video_80_cases_deep_dive.md` 更新，分别建立KB01–80与DD01–80索引，提炼三种目标、八类内容、四类风格与可选创意变换。两文存在重复题材，不宣称160个独立爆款。保留此前 `tiktok.docx` 的K/D/P索引作为历史资料；各批播放量、账号与产品效果未核验。

核心创作标准：**先确定观众值得等待的回报，再写清首屏、全程镜头与实现方法。产品反转用可见证据推翻前面的判断；纯内容用故事答案、可学方法或感官完成兑现开头。**

本次强化：先按至少70%无人分配方案，优先物件、操作与录屏，不默认全写人物剧情。原因揭秘不再自动计为欧亨利反转；逐条检查“原判断被什么画面推翻”、提前伏笔与结尾机制差异。

## 核心方法

1. **先分清故事机制**：误会重释、秘密工具、关系翻转，与情境解围、结果演示分别评价；不把所有产品效果都叫欧·亨利反转。
2. **以3秒内建立观看动机为目标**：先明确观众与回报，再选画面、文字、声音或结果过程主导。分别检查看懂、在意、愿意继续；封面与视频开头分开。写出准确首屏内容，不能靠填满三个节拍自证强钩子，结尾必须兑现承诺。
3. **产品故事保留最后一镜揭晓**：最后一镜可以从约 70% 处开始，连续完成揭晓和短反应。用户指定样本式多镜头收尾、提前露出、直接演示或硬广尾板时切换对应模式。纯内容不强加商品、70%翻牌或转化口令。
4. **单手机完成**：默认一个现成场景、最多两名总参与者、三件已有道具、3–6镜、1–2个手机摆位；自然光或现有灯，手机内硬切和字幕。不依赖第二手机、摄影团队、专业设备、定格或AI特效；每条明确手机怎么放、谁操作、怎么剪。用户明确要求其他制作规格时才切换。
5. **至少70%完全无人**：10条至少7条、5条至少4条，不出现手、身体、人像和倒影；其余优先仅手部或不露脸操作。默认无需露脸、对白和表情演技，幕后1人操作一部手机；用户明确要求其他配比时覆盖默认值。比例按创意数量计算。
6. **有依据才写效果**：未知型号不编参数，文档里的夸张性能不视为事实；循环必须交代实际接点，不机械加“因为——”。
7. **录屏可执行、证据可核对**：初始状态、实际操作、输出、核对贯通；Faceless、仅手部、完全无人分开，模拟界面不冒充实测。
8. **按形态验收**：产品故事的画面与文字共同建立具体冲突，结尾拍出翻案证据；双轨故事会分别检查讲述内线索与手部过程，教程/观点/治愈按实际回报检查，不硬造戏剧冲突。
9. **剪辑服务回报**：快节奏、荧光跳字、拟声音效和语句循环都是选择；安静过程可保留停顿，录屏须读得清，不采用无依据的留存阈值。
